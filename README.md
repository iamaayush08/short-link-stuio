# Short-Link Creation & Bot-Traffic Analytics Studio

**Mini Project – GLA University | Batch 1 | Section 3BA**

## Project Overview
A web-based application that combines URL shortening with bot-traffic analytics.

Users can generate short links from long URLs, customize aliases, manage destination URLs and expiry rules, and monitor incoming clicks.

The application uses a transparent, rule-based heuristic to classify simulated traffic as human or bot based on click intervals, request frequency, user-agent patterns and referrer consistency.

## Technology Stack
- Frontend: HTML, CSS, JavaScript, React.js
- Backend: Node.js / Express.js
- Database: MongoDB / MySQL
- Visualization: Chart.js / D3.js
- Version Control: Git & GitHub
